Trees the game has used

The game's own models, from its data and its own tree maker, in the order they came. Lit by this page's sun, not the game's look, so colours are close but not exact.

Triangles are for one tree. Draws are separate meshes per tree before batching; the game batches or instances them, so a wood of one style is one to three draws. B, C and D can share one tree's shape and differ only in shading, so any of them can be mixed with G for the far rows.
