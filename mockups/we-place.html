Which models (the big question: weight)

A · ALL 3,058
Every model, fetched only when someone places one or walks near one. A big bake (hours) and a lot of server space, but players' downloads stay small.
B · A PICKED SET (recommended to start)
The world-fitting categories first (street furniture, plants, rocks, fences, signs, lamps, market and shop props, about 400–600 models). Add more categories later.
C · ONLY SMALL THINGS
Props and furniture under a set size, with no buildings or vehicles, so nobody drops a skyscraper on Market St.
